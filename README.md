# CareerHub — Online Job Portal

A modern, responsive job portal designed to help users explore job opportunities, manage professional profiles, and track job applications. CareerHub features a clean user interface with a professional orange, white, and black theme.

## 🚀 Live Demo

**Month 02 — Intern Job Portal System:**  
[View Live Demo](https://preetamkumar9.github.io/Month_02_Intern_JOB_PORTAL_SYSTEM/)

## ✨ Features

- **Home Page:** Professional landing page with navigation and career-focused content.
- **Authentication:** Login and registration interface.
- **Find Jobs:** Browse and explore job opportunities.
- **My Profile:** Manage professional information, skills, education, and experience.
- **My Applications:** View and track job applications.
- **Responsive Design:** Layout adapts to desktop, tablet, and mobile screens.
- **Browser Storage:** Uses local storage for supported features that retain data in the browser.

*Note: The functionality available in the live demo depends on the features implemented in the deployed version.*

## 🛠️ Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling, responsive layouts, and UI design
- **JavaScript (ES6+)** — Interactivity and client-side functionality
- **Local Storage** — Browser-side data persistence
- **Git & GitHub** — Version control and hosting

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd CareerHub
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

## 🔐 Security Considerations

This project uses client-side technologies. Browser local storage is not suitable for securely storing passwords or sensitive personal information. Production authentication, Google sign-in, secure file uploads, and persistent multi-user data require appropriate backend services and security controls.
