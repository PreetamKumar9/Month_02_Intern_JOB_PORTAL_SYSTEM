Account & privacy

Understand how this front-end demonstration stores your information.

Browser storage, not a secure server

Profile details are saved in this browser's localStorage. Other people who can access this browser profile may be able to inspect that data. Do not store passwords, identity documents, or other highly sensitive information here.

You can export your profile as a JSON file for a local backup. The exported file may contain personal information, so store it carefully.

Clear this profile's saved data from this browser. This does not delete data from a remote server because this demo has no backend.
